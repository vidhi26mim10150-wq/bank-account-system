# Project Statement

## Project Title
Personal Bank Account Management System

## Problem Statement
Manual tracking of personal transactions can make it difficult to review
balance changes and calculate total deposits and withdrawals. This project
provides a simple local command-line system for one personal account.

## Scope
The system supports account creation, PIN login, balance checking, deposits,
withdrawals, simulated transfers, transaction history, financial summaries,
PIN management and JSON storage.

## Target User
An individual learning or demonstrating basic Python programming concepts
through a practical account-management application.

## Functional Requirements
1. Account creation
2. PIN-based login
3. Balance checking
4. Deposit
5. Withdrawal
6. Transfer simulation
7. Transaction history
8. Financial summary
9. PIN change
10. Local JSON storage

## Non-Functional Requirements
- Usability: simple numbered command-line menu.
- Reliability: local JSON persistence.
- Maintainability: separated Python modules.
- Error handling: validation and exceptions.
- Resource efficiency: Python standard library only.
- Security: PIN authentication for this educational simulation.

## Learning Objectives
Variables, conditionals, loops, functions, classes, exception handling,
file handling, JSON, modules, packages and unit testing.
