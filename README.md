# Personal Bank Account Management System

## Overview
A beginner-friendly Python command-line project for managing one personal
bank account. This is an educational simulation, not a real banking system.

## Features
- Create one account
- PIN login
- Check balance
- Deposit and withdraw
- Transfer simulation
- Transaction history
- Financial summary
- Change PIN
- JSON storage
- Input validation and error handling
- Unit tests

## Technology
Python 3, JSON, unittest, and the Python Standard Library.

## Run
```text
python main.py
```

## Test
```text
python -m unittest discover -s tests -v
```

## Important
Use only fake details for demonstrations. Do not put real bank details or a
real banking PIN in a student repository.
